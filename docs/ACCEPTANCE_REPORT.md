# FILM UNIT v0.1 — 검증 결과

검증일: 2026-09-11. 목적: 음원에서 실제 MP4까지 이어지는 Mock-first 제작 시스템 검증.

## 영상 출력

| 항목 | Test A | 60초 Mock Pilot |
|---|---:|---:|
| 요청 길이 | 30초 | 60초 |
| 실제 컨테이너 길이 | 30.000000초 | 60.000000초 |
| 연결한 샷 | 6 | 12 |
| 출력 해상도 | 1440×1080 | 1440×1080 |
| 프레임레이트 | 24fps | 24fps |
| 프레임 수 | 720 | 1440 |
| 실제 AI 생성 샷 | 0 | 0 |
| 유료 생성 크레딧 | 0 | 0 |
| 파일 | TEST_A_30S.mp4 | PILOT_60S.mp4 |

입력은 직접 합성한 65초 테스트 신호입니다. 음악은 원래 제공된 Suno 곡이 아니며, 도식은 최종 캐릭터·그림체가 아닙니다. 전체 65초 manifest를 변경하지 않고 30초와 60초 창을 각각 출력했습니다. 기본 분류 패턴은 STATIC 40%, LIMITED 40%, FULL 20%이고, Mock 모드에서는 모두 로컬 테스트 클립으로 만듭니다.

## 음원 검증

- 입력 원본 파일 SHA-256: 렌더 전후 동일.
- 최종 파일: H.264 영상 1개, 원본에서 만든 AAC 음성 트랙 1개.
- 출력의 60초 오디오를 16kHz mono로 디코딩한 샘플 수: 960,000개로 요청 길이와 일치.
- 동일 조건으로 디코딩한 원본과 출력의 파형 상관계수: 0.9999822674.
- AAC는 손실 인코딩입니다. 이 수치는 테스트 신호의 파형 보존·정렬 확인이며 원본 비트 보존을 의미하지 않습니다. 원본 파일 자체는 따로 보존됩니다.

## 엔진 검증

검증 항목은 실제 오류를 주입해 확인했습니다.

1. 최대 10분 타임라인의 절대 경계 반올림에서 프레임 누적 오차 없음.
2. LOCK 이후 첫 프레임 파일 변경 시 렌더 차단.
3. Mock용 LOCK으로 OpenArt 생산 렌더 시도 차단.
4. 샷 gap·overlap·잘못된 duration 거부.
5. 완전 무음 입력을 BPM 미검출·전체 무음으로 기록.
6. 최초 생성과 전체 재시도 여유분을 합한 예산·승인 확인.
7. 같은 작업 ID의 중복 예약 방지, 상한 초과 차단.
8. 인물·화풍 검사를 하지 않은 클립을 임의의 PASS 점수 없이 NEEDS_REVIEW로 보류.
9. 인물 점수만 실패해도 평균에 묻히지 않고 수정 근거를 다음 시도에 전달.
10. 클립 오디오 제거 및 최종 원곡 단일 트랙 확인.
11. 손상된 클립 반복 입력 시 재시도 2회 후 중단.
12. 가져온 클립을 같은 파일명으로 교체하면 캐시와 기존 QC 승인이 무효화됨.
13. 실제 조회한 OpenArt form으로 요청 검증; audio off; 동일 시도에서 요청 파일 하나만 생성; 중복 history ID 등록 차단; 견적 이후 설정 변경 감지.
14. 비정상 NaN 견적이 비용 상한을 우회하지 못하도록 거부.

OpenArt 테스트에서는 가짜 테스트용 견적·존재하지 않는 fixture URL을 사용했고, 네트워크 제출은 하지 않았습니다. Manual QC 테스트 역시 로컬 색상 영상에 대한 검증 fixture입니다. 이를 실제 AI 생성 성공으로 집계하지 않았습니다.

## Control Panel

Streamlit 실행 테스트에서 오류 없이 PROJECT, DIRECTOR, STORYBOARD, RENDER, FINAL 5개 탭이 생성됐습니다. 합성 샘플 65초, 추정 BPM 117.5, 검출 비트 128개, 콘티 13개 LOCK 상태가 표시됐습니다. “예상 비용 확인” 버튼 실행 결과 첫 생성 0 / 최대 0 credits가 표시됐습니다.

Work의 별도 브라우저가 로컬 주소 접근을 차단해 실제 브라우저 상호작용·픽셀 레이아웃 검증은 수행하지 못했습니다. 이 제한을 Streamlit 실행 검증과 혼동하지 않습니다.

## 남은 실제 제작 조건

최종 Suno MP3/WAV와 곡에 맞게 승인한 콘티가 필요합니다. 자동 시각 평가 모델은 아직 연결되지 않았으며 Work/사람의 근거 있는 QC 기록을 사용합니다. 실제 OpenArt 3샷 생성과 이를 포함한 60초 MV는 아직 완료하지 않았습니다. 비공개 GitHub 저장소 역시 현재 연결 도구에 생성 기능이 없어 생성·푸시하지 않았습니다.

전달물에는 소스, 문서, 테스트, 샘플 프로젝트, 로컬 Git 이력 bundle과 MP4가 포함됩니다.
