# 제작 작업실 (키보드 · 좁은 화면 · 오류)

`FRAME_ANIMATION_V1` 프로젝트의 `13 · 작업실` 탭입니다. `LEGACY_MV`에는
탭이 없고, 원곡·가사·검수·LOCK·타임라인은 이 화면이 쓰지 않습니다.

## 다음 행동

준비 → 동작 → 검토 → 수정 → 출력 중 지금 막힌 단계 하나만 문장으로
보여 줍니다. 그림 넣기, 움직임 계획, 검수, 수정, 잠금·최종 승인은
각각의 기존 화면에서 하고, 여기서는 그 순서를 안내합니다. 핵심 동작
(프레임 고르기, 확대, 동작 줄이기, 메모, 재시작 확인)은 입력칸과
버튼으로 끝나며 JSON 파일을 열지 않습니다.

상태는 글자와 기호입니다. 검수 완료 ✓, 실패 ✕, 진행 중 …, 미검수 ○.
색만으로 구분하지 않습니다.

## 키보드와 확대

위젯 순서는 좁은 화면, 동작 줄이기, 프레임 번호, 확대 단계, 메모,
이동 버튼, 기억 버튼입니다. 프레임 번호는 숫자와 화살표 키, 버튼은
Enter입니다. 이전/다음 프레임은 1칸, 이전/다음 구간은 확대 단계의
폭(1·8·24·96·480, 타임라인보다 길면 자름)입니다. 동작 줄이기는
애니메이션만 끄고 이동 칸 수는 바꾸지 않습니다.

저장이 거절되면 디스크의 선택 프레임과 메모는 그대로이고, 칸에 친
글은 남습니다.

## 빈 화면 · 자격 · 재시작

프로젝트가 없으면 만들기 화면에 빈 작업실 안내가 있습니다. 그림이
없는 컷은 준비 단계입니다. Google OAuth 클라이언트는 발급되어 있지
않아 자격은 항상 없음이며, 로그인을 시도하지 않습니다. 실행 저널이
잘렸거나 제출이 열려 있으면 재시작으로 표시하고, 확인 버튼은 기록만
하며 다시 제출하지 않습니다.

미리보기·이 화면의 기록은 작품 Final이 아닙니다. qualification
UNQUALIFIED · acceptance PENDING · release NOT_AUTHORIZED.

## 검증하지 못한 것

Streamlit AppTest는 실제 키 입력과 데스크톱 창 크기를 보지 않습니다.
브라우저에서 Tab 순서, 화살표 키, 880px 이하 배치를 확인하지
못했으면 미검증입니다.
